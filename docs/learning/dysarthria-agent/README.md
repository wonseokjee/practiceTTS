# 구음장애 음성 에이전트 — 개념자료

뇌졸중 등으로 인한 구음장애(dysarthria) 환자를 위한 음성 에이전트를 만들 때
무엇을 알아야 하고, 데이터가 있다면 무엇을 학습시켜야 하는가.

일반 음성 에이전트를 다룬 [../voice-agent-book/](../voice-agent-book/README.md)의
전제 상당수가 여기서는 뒤집힙니다. 특히 종단 감지와 끼어들기는 정반대로 설계해야
합니다. 그 책을 먼저 읽었다면 **어디가 뒤집히는지**에 주목하며 읽으면 좋습니다.

## 이 자료가 전제하는 것

- 구음장애 발화 데이터를 어느 정도 확보한 상태
- 목표는 논문이 아니라 **환자가 실제로 쓸 수 있는 제품**
- 완벽한 인식은 불가능하다는 전제 위에서 설계

## 이 자료를 관통하는 세 문장

**하나.** 구음장애는 언어 장애가 아니라 말 산출의 운동 장애다. 환자는 무슨 말을
하고 싶은지 정확히 알고 있다. 이걸 놓치면 설계 전체가 어긋난다.

**둘.** "알아듣는 에이전트"와 "발음을 교정하는 에이전트"는 목표가 정반대다.
하나의 시스템에 섞으면 둘 다 실패한다.

**셋.** 인식률을 끝까지 올리는 것보다, 못 알아들었을 때 무엇을 하는지가 제품의
성패를 가른다.
