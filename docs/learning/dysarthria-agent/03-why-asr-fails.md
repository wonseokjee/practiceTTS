# 03. 왜 기존 ASR이 무너지는가

## 성능이 떨어지는 게 아니라 무너진다

일반 STT 모델에 구음장애 발화를 넣으면 정확도가 조금 낮아지는 정도가 아닙니다.
심도가 올라가면 **거의 쓸 수 없는 수준**이 됩니다.

보고되는 수치는 코퍼스와 모델에 따라 편차가 크지만, 대체로 이런 양상입니다.

```
정상 발화        오류율 5% 내외
경도 구음장애     20~30%대
중등도           40~60%대
중도 이상        70% 이상, 사실상 무의미
```

**낙폭이 선형이 아니라는 점**이 중요합니다. 경도에서 중등도로 갈 때보다 중등도에서
중도로 갈 때 훨씬 가파르게 무너집니다. 어느 지점을 넘어가면 모델이 아예 다른
문장을 만들어냅니다.

왜 이렇게 되는지를 이해해야 무엇을 고칠지 알 수 있습니다.

## 원인 하나: 학습 분포 밖의 데이터

가장 근본적인 이유입니다. 상용 ASR 모델은 압도적으로 정상 발화로 학습되었습니다.
구음장애 발화는 학습 데이터에 거의 없거나, 있어도 극소수입니다.

모델 입장에서는 **처음 보는 종류의 소리**입니다. 그리고 딥러닝 모델은 학습
분포를 벗어난 입력에서 신뢰할 수 없는 방식으로 실패합니다. 조금 틀리는 게
아니라 자신 있게 엉뚱한 답을 냅니다.

여기에 대형 모델 특유의 문제가 겹칩니다. 강력한 언어 모델을 내장한 ASR은
알아듣기 어려운 구간에서 **그럴듯한 문장을 지어냅니다**(환각). 침묵이나 잡음
구간에서 있지도 않은 문장을 생성하기도 합니다. 오인식보다 위험한데, 결과물이
자연스러워서 틀린 줄 모르기 때문입니다.

## 원인 둘: 소리 자체가 다르다

구음장애 발화의 음향적 특징을 하나씩 보면, 각각이 ASR의 어떤 가정을 깨는지
드러납니다.

### 조음 부정확 — 자음이 뭉개진다

혀와 입술의 정밀한 움직임이 어려워지면서 자음이 흐려집니다. 특히 정확한 위치와
타이밍이 필요한 소리들이 먼저 무너집니다.

```
파열음 (ㄱ, ㄷ, ㅂ)  — 폐쇄와 개방의 타이밍이 어긋남
마찰음 (ㅅ, ㅆ, ㅎ)  — 좁은 틈을 유지하지 못해 흐릿해짐
유음   (ㄹ)          — 혀끝 움직임이 어려움
```

앞 책 4장에서 전화망 8kHz가 마찰음을 잘라낸다고 했습니다. **구음장애 환자가
전화를 쓰면 두 손상이 겹칩니다.** 이미 흐릿한 마찰음이 대역 제한으로 한 번 더
깎입니다. 전화 기반 서비스를 설계한다면 이 중첩을 반드시 고려해야 합니다.

### 모음 중앙화 — 모음 공간이 좁아진다

혀의 운동 범위가 줄어들면서 모든 모음이 중앙(ㅓ에 가까운 소리)으로 몰립니다.

```
정상:  ㅣ  ㅔ  ㅏ  ㅗ  ㅜ    ← 넓게 퍼져 구별됨
장애:      ㅔㅏㅓㅗ           ← 좁게 뭉쳐 구별 어려움
```

모음은 음성 인식에서 가장 신뢰할 만한 단서였는데, 그 신뢰가 깨집니다.
임상에서 명료도를 정량화할 때 **모음 공간 면적**을 지표로 쓰는 이유이기도 합니다.

### 말속도 저하와 음절 지속시간 증가

말이 느려지고 각 음절이 길어집니다. 정상의 절반 이하 속도가 되기도 합니다.

ASR 모델은 대개 정상적인 말속도 범위를 전제로 시간 축 특징을 학습합니다.
지나치게 느린 발화는 모델이 음소 경계를 잡는 방식과 어긋납니다.

### 부적절한 쉼 — 발화 중간의 긴 침묵

호흡 조절이 어려워 한 호흡에 말할 수 있는 길이가 짧아집니다. 그래서 문장
중간에 숨을 쉬느라 멈춥니다.

```
"물 [1.8초] 좀 [2.2초] 주세요"
```

**이것이 종단 감지를 파괴합니다.** 일반적인 침묵 기반 종단 감지는 이 발화를
세 개의 별개 발화로 쪼갭니다. 7장에서 다시 다룹니다.

### 음질 이상

| 증상 | 소리 | 원인 |
|---|---|---|
| 기식음 (breathy) | 바람 새는 소리 | 성대 폐쇄 부족 |
| 쥐어짜는 소리 (strained) | 힘든 목소리 | 성대 과긴장 |
| 과다비성 (hypernasal) | 코맹맹이 | 연구개 폐쇄 부족 |
| 음량 저하 | 작은 소리 | 호흡 지지 부족 |
| 음도 불안정 | 떨리거나 튐 | 조절 저하 |

과다비성이 특히 성가십니다. 코로 소리가 새면 구강 자음의 특성이 흐려져서
서로 다른 자음이 비슷하게 들립니다.

### 운율 소실

강세, 억양, 리듬이 평평해집니다. 문장의 경계나 강조가 소리에 드러나지 않습니다.

의미 전달에서도 손해지만, **종단 감지에서 특히 아픕니다.** 앞 책 7장에서 문장
끝의 억양 하강이 종료 신호가 될 수 있다고 했는데, 그 신호가 사라집니다.

## 원인 셋: 변동성

여기까지는 "일정하게 왜곡되어 있다"는 전제였습니다. 일정하다면 배울 수 있습니다.

문제는 **같은 사람이 같은 단어를 매번 다르게 발음한다**는 것입니다. 화자 내
변동성이 정상인보다 훨씬 큽니다.

변동을 만드는 요인들이 있습니다.

- **피로** — 세션 후반으로 갈수록 나빠짐
- **약물** — 파킨슨 환자는 복약 주기에 따라 크게 달라짐
- **시간대** — 아침과 저녁의 컨디션 차이
- **자세** — 앉은 자세, 목의 각도
- **정서** — 긴장하면 더 나빠짐

이것이 두 가지를 시사합니다.

**하나.** 소량 데이터로 개인화할 때, 그 데이터가 특정 컨디션에 치우쳐 있으면
다른 컨디션에서 안 통합니다. 수집 시점을 분산해야 합니다.

**둘.** 단일 예측보다 **여러 후보를 유지하는 편**이 유리합니다. 변동성이 크다는
것은 하나의 정답에 확신할 수 없다는 뜻이므로, 후보를 남겨두고 나중 단계에서
고르는 구조가 견고합니다. 6장의 주제입니다.

## 원인 넷: 데이터가 적다

정상 발화 데이터는 수십만 시간 단위로 존재합니다. 구음장애 발화 데이터는 공개
코퍼스를 다 합쳐도 수십~수백 시간 수준입니다.

그런데 필요한 다양성은 오히려 더 큽니다.

```
필요한 축:  유형(7가지) × 심도(4단계) × 화자 개인차 × 언어
```

**정상 발화보다 훨씬 다양한데 데이터는 훨씬 적습니다.** 이 불균형이 이 분야의
근본 제약이고, 5장의 전략(개인화, 증강, 사전학습 활용)이 전부 여기서 나옵니다.

## 무너지는 방식을 정리하면

| 증상 | 깨뜨리는 가정 | 대응 방향 |
|---|---|---|
| 자음 뭉개짐 | 음소가 구별된다 | 화자 적응, 어휘 제약 |
| 모음 중앙화 | 모음이 신뢰할 단서다 | 화자 적응 |
| 느린 말속도 | 정상 속도 범위 | 속도 증강, 적응 |
| 발화 중 긴 쉼 | 침묵 = 발화 종료 | **종단 감지 재설계** |
| 운율 소실 | 억양이 경계를 알려준다 | 종단 감지 재설계 |
| 큰 변동성 | 같은 말은 같은 소리 | 다중 후보, 분산 수집 |
| 데이터 부족 | 충분한 학습 데이터 | 사전학습 + 개인화 |

**오른쪽 열이 이후 장들의 목차입니다.** 그리고 눈여겨볼 것은, 절반 이상이
"인식 모델을 고친다"가 아니라 **"시스템 설계를 바꾼다"**라는 점입니다.

인식률을 올리는 데는 한계가 있습니다. 중도 환자에게서 오류율을 70%에서 40%로
낮춰도 여전히 실용적이지 않습니다. 그 지점부터는 **못 알아들었을 때 무엇을
하는가**가 제품의 성패를 가릅니다.

---

**한 문장 요약**
구음장애 발화는 학습 분포 밖에 있고, 자음·모음·속도·운율이 모두 ASR의 가정을
깨며, 변동성은 크고 데이터는 적어서 인식률 향상만으로는 한계가 분명하다.
