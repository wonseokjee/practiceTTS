# 음성 AI 에이전트 학습 자료

LLM 기반 음성 AI 에이전트를 설계·배포하기 위한 7단계 학습 커리큘럼입니다.
각 문서는 **학습 목표 → 핵심 개념 → 코드 → 실습 과제 → 자가진단** 순서로 구성되어 있습니다.

## 전체 구조

```
4층  도메인·비즈니스   Phase 5, 6, 7
3층  전송(텔레포니)    Phase 4        ← 차별화 지점
2층  실시간 음성 코어   Phase 3        ← 최중요
1층  에이전트 기반      Phase 1, 2
```

## 학습 방법

**읽고 넘어가지 말 것.** 각 문서의 "실습 과제"를 실제로 돌려본 뒤 다음 단계로 갑니다.
Phase 3·4는 직접 만들어본 사람과 읽기만 한 사람의 차이가 가장 크게 벌어지는 구간입니다.

**시간이 부족하면** Phase 3 → 4 → 6 → 2 → 1 → 5 → 7 순서로 자르세요.
1층(AI SDK·Mastra·BAML)은 문서 며칠이면 따라잡히지만, 실시간 음성 지연 튜닝과
텔레포니는 굴려본 사람만 알 수 있는 영역입니다.

## 라이브러리 버전 주의

이 분야는 라이브러리가 매우 빠르게 바뀝니다. 문서의 코드는 **개념을 설명하기 위한
형태**이며, 실제 작성 시에는 반드시 각 프로젝트의 최신 공식 문서로 시그니처를 확인하세요.
특히 다음은 최근 1년 사이 breaking change가 있었습니다.

- Vercel AI SDK: v4 → v5에서 `parameters` → `inputSchema`, `maxSteps` → `stopWhen`
- Langfuse: v2 → v3에서 OpenTelemetry 기반으로 전면 교체
- LiveKit Agents: 0.x → 1.x에서 `VoicePipelineAgent` → `AgentSession`
