## 이 책이 다루는 것

전화를 받아 사람과 대화하고, 실제로 일을 처리하는 AI 에이전트가 어떤 원리로
동작하는지. 라이브러리 사용법이 아니라 **왜 그렇게 만들 수밖에 없었는가**를 다룹니다.

각 장은 같은 뼈대로 쓰였습니다.

> 문제가 무엇인가 → 처음엔 이렇게 풀려고 한다 → 그런데 이렇게 깨진다 →
> 그래서 실제로는 이렇게 한다 → 아직 남아 있는 질문

읽고 나면 코드를 쓸 수 있는 건 아니지만, 남이 쓴 코드를 보고 "여기서 왜 이걸
하는지"를 알게 됩니다. 그게 이 책의 목표입니다.

## 읽는 법

**순서대로 읽는 것을 권합니다.** 뒷 장이 앞 장의 개념을 계속 되부릅니다.
특히 3부는 2부의 8kHz와 지터 개념 위에 서 있습니다.

시간이 아주 부족하면 **1부 → 3부 → 5부**만 읽어도 전체 그림은 잡힙니다.
2부(전송 계층)와 4부(에이전트 구현)는 필요할 때 돌아와도 됩니다.

각 장 끝에는 "한 문장 요약"과 "스스로 답해보기" 세 문항이 있습니다. 답이 막히면
그 장을 다시 읽으라는 신호입니다. 문답집은 전체를 한 번 훑은 뒤에 쓰는 편이 좋습니다.
