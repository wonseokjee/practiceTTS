# 발화 채점 등급 임계값이 짧은 단어에서 무너진다

> 발견일: 2026-08-16
> 상태: 미해결 (부채 기록)
> 관련 코드: `frontend/src/memory-link/patient/quiz/domain/pronunciationScore.ts`,
> `frontend/src/memory-link/patient/quiz/domain/speechScore.ts`
> 발견 경위: 608 ASR 평가에서 단어 CER의 분모가 1.4자라는 걸 확인하다가,
> 앱 채점기가 같은 구조라는 것으로 이어졌다 (`docs/asr/608-finetune-log.md`)

## 증상

발화 정확도 5단계 등급이 **짧은 목표 단어에서 대부분 도달 불가능**하다.

오류율 = 편집거리 / **목표 음절 수**이므로, 목표가 짧으면 오류율이 띄엄띄엄한
값만 가진다.

| 목표 길이 | 가능한 오류율 | 도달 가능한 등급 |
|---|---|---|
| 1음절 | 0, 1, 2, … | **perfect / retry** 뿐 |
| 2음절 | 0, 0.5, 1, … | **perfect / close / retry** 뿐 |
| 3음절 | 0, 0.33, 0.67, … | perfect / good / retry |
| 4음절 | 0, 0.25, 0.5, … | perfect / good / close / retry |
| 7음절+ | 0, 0.14, … | 비로소 **great**(≤0.15) 도달 |

현재 임계값(`great` 0.15 · `good` 0.34 · `close` 0.5)은 **문장 길이를 전제로**
잡혀 있다. 그런데 그림 이름대기·단어 따라말하기의 목표는 대부분 2~3음절이다.

즉 단어 과제에서는 사실상 **맞음/틀림 이진 판정**이 돌아가고, 중간 등급의 격려
문구는 거의 안 나오거나 목표 길이에 따라 들쭉날쭉하게 나온다.

## 왜 문제인가

등급은 **환자에게 보이는 유일한 피드백**이다. 숫자 점수는 보호자에게만 가고
환자에게는 격려 문구만 노출한다(`ENCOURAGEMENT`).

- "거의 다 왔어요"가 나와야 할 아까운 시도가 "다시 해볼까요?"로 떨어진다
- 같은 정도로 잘한 발화가 **목표 단어 길이에 따라** 다른 등급을 받는다
  (2음절에서 1개 틀리면 0.5 → close, 3음절에서 1개 틀리면 0.33 → good)
- 재활에서 부분 성공을 인정받는 경험은 순응도와 직결된다 — 이 앱의 설계 원칙
  자체가 "비처벌·성공 경험"이다

## 완화하고 있는 것

`speechScore.ts`의 단어 모드는 표준 편집거리가 아니라 `phoneticEditDistance`를
쓴다. 조음 유사 혼동(ㅂ↔ㅍ, 종성 탈락 등)에 1보다 작은 비용을 매기므로 오류율이
정수 배수로만 떨어지지는 않는다. 완전한 이진은 아니라는 뜻이다.

그래도 **해상도가 낮은 건 그대로다.** 1음절 목표에서는 부분 비용이 붙어도
경계(0.15/0.34)를 넘나드는 폭이 크다.

## 고칠 방향 (미결정)

1. **목표 길이별 임계값** — 짧은 목표에는 완화된 경계를 쓴다. 단순하지만 경계가
   여러 벌이 되어 설명하기 어려워진다.
2. **음소 단위 오류율** — 음절 대신 자소(초성·중성·종성)로 분모를 키운다.
   2음절 단어도 분모가 4~6이 되어 등급 해상도가 생긴다. `phoneticDistance`가
   이미 자소를 다루므로 재사용 여지가 있다.
3. **등급 수를 목표 길이에 맞춰 줄인다** — 짧은 단어에는 3단계만 쓰고, 그걸
   명시적으로 설계한다. 지금은 5단계인 척하면서 실제로 2~3단계인 게 문제다.

**2번이 유력해 보인다.** 분모를 키우는 게 근본 해법이고, 조음 오류를 자소 수준에서
보는 게 임상적으로도 자연스럽다(종성만 빠졌는지, 초성이 바뀌었는지).

## 먼저 확인할 것

고치기 전에 **실제 분포부터 봐야 한다.** 지금까지 쌓인 `qab_results`에서
따라말하기·읽기·이름대기 항목의 목표 길이와 등급 분포를 뽑으면, 이 문제가
이론상 문제인지 실제로 환자가 겪고 있는 문제인지 갈린다.

- 목표가 실제로 몇 음절인지 (문항 풀 기준)
- 등급별 빈도 — `great`가 정말 0에 가까운지
- 같은 환자가 목표 길이에 따라 등급이 흔들리는지

측정 없이 임계값을 바꾸면 다른 방향으로 틀어질 수 있다.
