## 🔬 1. 아키텍처 및 핵심 로직: Word → CER (Character Error Rate) 전환

### [문제 해결] 한국어 띄어쓰기 오류 선제 방어
STT가 반환하는 문맥 띄어쓰기에 점수가 좌우되던 기존의 불합리한 구조를 폐기했습니다. **`cerCalculator.ts`** 도메인 함수를 신설하여 한국어 평가에 가장 알맞은 채점 기준을 도입했습니다.

```typescript
// 공백 및 기호 100% 제거하는 정규화
export function normalizeKoreanText(text: string): string {
  return text.replace(/[^가-힣a-zA-Z0-9]/g, "");
}
```

- 단순히 띄어쓰기 하나 틀렸다고 0점 처리되는 오류를 완전 차단.
- `cerCalculator.test.ts` 단위 테스트 코드 작성을 통해, "단어 길이가 너무 짧아 점수가 과하게 깎이는 케이스"와 "침묵 케이스" 등 엔지니어링 뷰에서 도출된 **11개 엣지 케이스들을 100% 대응**시켰습니다.

## ⏱️ 2. 하이브리드 생명주기 제어 및 최적화

### VAD Throttling 최적화 (`useVAD.ts`)
웹 메인 스레드에서 매 프레임 음소거 여부를 체크하던 마이크 데시벨 연산을 **100ms**(`requestAnimationFrame` 내부 타임스탬프 필터링) 주기로 과감히 제한했습니다.
- 저사양 스마트폰 브라우저라도 프레임(FPS) 드랍 없이 쾌적하게 동작합니다.

### 환자 중심 배려형 타이머 체계 (`useRepetitionViewModel.ts`)
- **절대 타임아웃 15초:** 환자에게 생각하고 대답할 넉넉한 15초 제한 시간을 기본으로 보장합니다.
- **5초 침묵(Silence) 대기:** 환자가 말을 하다 멈추더라도('단어 찾기 어려움' 증상) VAD 감지 엔진이 바로 끊지 않습니다. 발화가 시작된 기점으로 연속 5초간 침묵해야만 비로소 답을 마친 것으로 판단해 부드럽게 넘깁니다.
