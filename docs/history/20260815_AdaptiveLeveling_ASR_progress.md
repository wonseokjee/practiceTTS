## 1. 트랙 A — 적응형 학습 (에픽 #27)

### 1-1. 목표 / 배경
환자가 혼자 매일 하는 적응형 재활 세션. 보호자 의존(순응도 최대 방해물) 제거. 현재 문항 선택이 무작위 셔플(`frontend/.../QabItemBank.ts` `pickQabItems`)이라 적응성이 0이고 난이도가 고정 — 이게 실질 갭이었다. CEO+Eng+Design 3중 리뷰 통과 후 구현.

### 1-2. 확정 아키텍처 결정
| 결정 | 내용 | 근거 |
|---|---|---|
| 데이터 모델 | `skill_levels`(patient×subtest×level 1..5, UPSERT) + `qab_results.presented_level` | 최소 확장. qab_results가 이미 이력·정확도·assisted·멱등 인덱스 보유 |
| 레벨 규칙 | 최소 5시행 hold, ≥80% +1, <50% −1, 50~79% 데드밴드, [1..5] 클램프 | 승급 직후 유도하락을 퇴행으로 오독하는 진동 차단(presented_level 격리) |
| 발화 홀드 | 발화(naming/repeat/reading)는 score=null(Azure 불가) 항목을 윈도우 제외 | 비처벌 |
| 콜드스타트 | 전 스킬 레벨 2 시작 | 성공 경험·비처벌 원칙 (Codex는 placement 선호 — 관측성으로 실측) |

## 2. 트랙 B — 자체 ASR 파인튜닝 (608 구음장애)

### 2-1. 목표 / 배경
앱 발화 과제는 대부분 **단어 수준**(그림 이름대기·단어 따라말하기)이라 범용 whisper에 가장 불리(단어나열 CER 0.70). 자체 ASR·개인화의 1순위 타깃 = 단어 수준 구음장애 인식. prompt-biasing은 실측상 유해 → 음향 LoRA 파인튜닝으로 방향 확정.

### 2-2. 실측 결과 (whisper-small LoRA, Colab T4)
| 실험 | 학습 규모 | test set | CER 전 → 후 | 판정 |
|---|---|---|---|---|
| 스모크 | 40분·178세그 | 소량 | — (train loss 0.003) | 과적합(암기), 이득 0 |
| 1차 | 372세그·화자~20 | 35세그·화자3 | **0.816 → 0.424** | 먹힘 (−47% 상대) |
| 2차 | 751세그·화자21 (단어세그 포함) | 94세그·화자5 | **0.816 → 0.656** | 먹힘 (더 어려운 test) |

> ⚠️ **CER은 test set이 배치마다 달라 cross-batch로 비교하면 안 된다.** 2차의 test는 단어 세그먼트(앱 최약점)를 포함해 더 어렵다. 유효한 비교는 **같은 실행의 전 vs 후**뿐. 두 배치 모두 후 < 전 → 파인튜닝 유효. 곡선 아직 오르막(포화 신호 없음) → 데이터 증량이 확실한 레버.

### 2-3. 파이프라인 (로컬 정렬 → Colab 학습)
```
TS01.zip (원본 425 wav)
  → select_608_batch2.py   (완료분 제외 + 화자 다양성 선택 + wav 추출 + 매니페스트)
  → align_608.py --wordlist auto  (문장/단어 자동 판별, whisper 앵커 정렬, 재개 가능)   [로컬 CPU, 수 시간]
  → prepare_colab_trainset.py     (배치 병합 + 화자 분리 split + zip)
  → Colab (finetune_whisper_608_colab.ipynb, T4 GPU)
```
- **단어 모드**: 단어 나열 파일(문장부호 없음)을 whisper 단어 타임스탬프에 정답 단어를 앵커해 단어(1~3개)별로 자름. 실측 12분 파일 1개 → 52 단어클립(0.7~2s).
- **재개**: `_attempted.txt` + segments 파일 단위 flush. 컴퓨터 종료해도 같은 명령 재실행으로 이어서 정렬(손상된 줄 가드 포함).

### 2-4. 배치 현황
| 배치 | 파일 | 세그먼트 | 상태 |
|---|---|---|---|
| 1차 `_segs_big` | 48 (짧은 파일) | 372 | 완료 |
| 2차 `_segs_big2` | 25 선택 중 13 완료 | 379 | 부분 완료(종료로 중단, 재개 가능) |
| 병합 `_segs_merged` | — | 751 | `colab_trainset_big2.zip`(train 518/test 94) |
| 3차 `_segs_big3` | 40 (화자 40 전원 신규) | 정렬 중 | 🟡 백그라운드 진행 |

> **주의**: `_segs_big`/`_segs_big2`/`_segs_big3` 원시 폴더는 재패키징에 필요 — 삭제 금지.

### 2-5. 후속
- 3차 정렬 완료 → 1+2+3 병합 재패키징 → Colab 재학습(목표 < 0.424, 단어 데이터 대폭 증가).
- 그 다음 레버: whisper-medium. 완성 후 앱 발화 과제(따라말하기·읽기) 실전 판정에 투입 검토.
